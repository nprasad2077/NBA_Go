## DigitalOcean MCP Servers

Use MCP servers to manage DigitalOcean services from any MCP-compatible client.

- [Configure Remote MCP](https://docs.digitalocean.com/reference/mcp/configure-mcp/index.html.md): Configure your MCP client to connect to DigitalOcean's hosted remote MCP servers.
- [Configure Local MCP](https://docs.digitalocean.com/reference/mcp/use-local-mcp/index.html.md): Configure the local MCP server to run on your machine and manage your DigitalOcean resources.
- [DigitalOcean MCP Tools](https://docs.digitalocean.com/reference/mcp/mcp-tools/index.html.md): DigitalOcean MCP services provide tools that let your MCP client interact with the API and perform various operations on your resources.
- [General Prompting Guidelines](https://docs.digitalocean.com/reference/mcp/prompting/index.html.md): Use effective prompts to manage DigitalOcean services from any MCP-compatible client.
- [Functions](https://docs.digitalocean.com/reference/mcp/functions-mcp-tools/index.html.md): Create, manage, and invoke serverless functions, namespaces, and triggers.
- [Agent Evaluations](https://docs.digitalocean.com/reference/mcp/agent-evaluations-mcp-tools/index.html.md): Manage evaluation datasets, run evaluations against agent deployments, and monitor results.
- [Batch Inference](https://docs.digitalocean.com/reference/mcp/batch-inference-mcp-tools/index.html.md): Submit, monitor, and retrieve results from asynchronous batch inference jobs.
- [Container Registry](https://docs.digitalocean.com/reference/mcp/container-registry-mcp-tools/index.html.md): Create, configure, and manage container registries, repositories, and garbage collection.
- [Dedicated Inference](https://docs.digitalocean.com/reference/mcp/dedicated-inference-mcp-tools/index.html.md): Create, update, list, and delete Dedicated Inference endpoints.
- [Documentation](https://docs.digitalocean.com/reference/mcp/documentation-mcp-tools/index.html.md): Search, browse, and retrieve DigitalOcean documentation pages without authentication.
- [Network File Storage](https://docs.digitalocean.com/reference/mcp/nfs-mcp-tools/index.html.md): Create and manage Network File Storage shares and access rules.
- [Volumes Block Storage](https://docs.digitalocean.com/reference/mcp/volumes-mcp-tools/index.html.md): Create, attach, detach, and manage Volumes Block Storage volumes and volume snapshots.
- [Model Catalog](https://docs.digitalocean.com/reference/mcp/model-catalog-mcp-tools/index.html.md): Search and view model details from Model Catalog through MCP.
- [Knowledge Bases](https://docs.digitalocean.com/reference/mcp/kbaas-mcp-tools/index.html.md): Query, filter, and retrieve content from knowledge bases through MCP.
- [Accounts](https://docs.digitalocean.com/reference/mcp/accounts-mcp-tools/index.html.md): View and manage account details, billing history, SSH keys, and balances.
- [App Platform](https://docs.digitalocean.com/reference/mcp/apps-mcp-tools/index.html.md): Deploy, update, and manage apps with builds, deployments, and environment variables.
- [DBaaS](https://docs.digitalocean.com/reference/mcp/dbaas-mcp-tools/index.html.md): Manage databases, users, and backups for managed database clusters.
- [DOKS](https://docs.digitalocean.com/reference/mcp/kubernetes-mcp-tools/index.html.md): Access Kubernetes clusters, deploy workloads, and manage nodes and configurations.
- [Droplets](https://docs.digitalocean.com/reference/mcp/droplet-mcp-tools/index.html.md): Create, modify, and control virtual machines, snapshots, and power actions.
- [Insights](https://docs.digitalocean.com/reference/mcp/insights-mcp-tools/index.html.md): Create, modify, and manage uptime checks, alert policies, and resource metrics.
- [Marketplace](https://docs.digitalocean.com/reference/mcp/marketplace-mcp-tools/index.html.md): Browse and deploy 1-Click applications on Droplets or Kubernetes clusters.
- [Networking](https://docs.digitalocean.com/reference/mcp/networking-mcp-tools/index.html.md): Manage domains, DNS records, firewalls, load balancers, reserved IPs, and VPCs.
- [Spaces](https://docs.digitalocean.com/reference/mcp/spaces-mcp-tools/index.html.md): Create and manage Spaces access keys for S3-compatible object storage.
